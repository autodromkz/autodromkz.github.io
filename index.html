AUTODROMKZ — USER GUIDE

ОБЩАЯ ИНФОРМАЦИЯ

Данный симулятор автодрома полностью повторяет реальный автодром автоцона г. Алматы — Саялы.

Трасса построена по реальной экзаменационной схеме: разметка • дорожные знаки • штрафные зоны.

Цель — подготовка к практическому экзамену по вождению.

РЕЖИМЫ ОБУЧЕНИЯ

Пользователю доступны 2 режима:

01 — СВОБОДНОЕ ВОЖДЕНИЕ
Free Driving Mode

  • Движение без ограничений
  • Нет указателей маршрута
  • Нет подсказок и предупреждений
  • Подходит для опытных водителей

Используется для тренировки навыков без помощи системы.

02 — РЕЖИМ ЭКЗАМЕНА
Exam Mode

Система автоматически начисляет штрафные баллы по правилам реального автоЦОНа.

Для успешного прохождения: сумма штрафных баллов не должна превышать допустимый лимит.

ВАРИАНТЫ ЭКЗАМЕНА

Режим экзамена делится на 3 уровня помощи:

LEVEL 1 — ПОЛНЫЕ ПОДСКАЗКИ

  • Зеленые указатели маршрута
  • Подсказки расположения штрафных зон
  • Подсказки как избежать штрафов

Подходит для обучения.

LEVEL 2 — ТОЛЬКО МАРШРУТ

  • Отображаются только зеленые указатели
  • Подсказок по штрафам нет

Подходит для подготовки к экзамену.

LEVEL 3 — РЕАЛЬНЫЙ ЭКЗАМЕН

  • Нет указателей маршрута
  • Нет подсказок системы
  • Только правила и навыки водителя

Подходит для опытных пользователей.

ЦЕЛЬ ТРЕНИРОВКИ

Отработать выполнение экзаменационных упражнений и подготовиться к реальной сдаче на автодроме.
